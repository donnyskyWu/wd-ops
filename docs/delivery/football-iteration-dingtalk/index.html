交付说明

用途：基于 UX-Football-钉钉同步与消息推送.md 的静态 HTML 线框，模拟 Element Plus / Vben Admin 布局与控件文案。

打开方式：直接用浏览器打开本页 index.html，或点击下方链接进入各页面原型。
