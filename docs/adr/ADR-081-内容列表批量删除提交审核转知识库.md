## 1. 背景

P-M2-006 内容列表已有行内「提交审核 / 转知识库 / 删除」，表格已有勾选列但无批量工具栏。产品要求对勾选行做批量操作。

## 2. 决策

| 项 | 决策 |
|----|------|
| **D1** | **不新增**批量 API。逐条调用现有：`DELETE /ops/content/{id}`、`POST /ops/content/{id}/submit-review`、`POST /ops/content/{id}/transfer-to-knowledge`。权限与单条相同。 |
| **D2** | 资格与行内按钮一致，不合格 **跳过不报 1500 挡整批**： |
| | 删除 / 提交审核：`DRAFT` 或 `REJECTED` |
| | 转知识库：`PENDING_PUBLISH` \| `PUBLISHED_DRAFT` \| `FORMALLY_PUBLISHED` \| `PUBLISHED` 且 `transferredToKnowledge≠1`（与现网行内 `canTransferKnowledge` 一致；宽于 ADR-023 原文仅 `PUBLISHED`） |
| **D3** | 勾选范围为 **当前页** `el-table` selection。 |
| **D4** | 二次确认后串行执行；结果 toast：`成功 N · 跳过 M · 失败 K`。部分失败不回滚已成功项。 |
| **D5** | 未选行：按钮禁用。合格数为 0：提示「所选内容均不符合该操作条件」，不发请求。 |

## 3. 后果

- 列表工具栏增加三个批量按钮；无 Flyway。
- 单条失败仍由现有错误码处理（如 2010）。
