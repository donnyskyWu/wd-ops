# ADR-075：工作任务登记 — 合并执行组（单行单赛 + 合并 confirm）

| 字段 | 值 |
|------|---|
| 编号 | ADR-075 |
| 标题 | 任务登记保持单行单赛；同营销计划多行「合并执行」后共享一套 SOP task |
| 状态 | **Accepted** |
| 日期 | 2026-08-31 |
| 关联 | [ADR-074](./ADR-074-工作任务登记SOP全节点生成与营销计划绑定.md) · [PRD-M2-工作任务管理](../product/PRD-M2-工作任务管理.md) |

---

## 1. 背景

ADR-074 D4 允许 **一行多赛事**，导致任务管理矩阵左侧赛事信息展示为「N 场」摘要，影响可读性。

产品 Owner 决议：**登记列表仍一行一场**；需合并执行时，勾选 **同作者 + 同营销计划** 的多行，点 **「合并执行」**；场次列展示 **「合并N」** 标签；confirm 仍为 **一套 SOP 全节点 task**（task 携带全部赛事 JSON）。

---

## 2. 决策

| # | 决策 |
|---|------|
| **D1** | 登记行 UI **恢复单场赛事**选择（不再一行内多选赛事）。 |
| **D2** | `oa_work_task_assignment.execution_group_id` BIGINT NULL；同 sheet 内相同 ID = 合并组。 |
| **D3** | **合并条件**：≥2 行 · 未 confirm · 已选赛事 · **同 `marketing_plan`** · **同 `author_id`**。 |
| **D4** | **confirm**：同组合并组只生成 **1×SOP 节点数** task；各行的 `assignment_task` 均关联同一批 task；`generated_task_id` 相同。 |
| **D5** | **withdraw**：选中合并组任一行 → 自动展开整组撤回。 |
| **D6** | 矩阵 Tab **不变**：仍按 **单行单场** 展示（每行独立赛事列）。 |

---

## 3. API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/ops/work-task/sheet/merge-execution` | `{ sheetId, assignmentIds[] }` |
| POST | `/ops/work-task/sheet/unmerge-execution` | 清除 `execution_group_id`（未 confirm 行） |

---

## 4. 与 ADR-074 关系

- ADR-074 D4「一行多赛事」在 **登记 UI** 上由 ADR-075 **取代**；`competition_ids_json` 仍可用于 task 携带合并组全部赛事。
- ADR-074 D5/D6 confirm 生成逻辑 **保留**，合并组走 **组级 confirm** 分支。
