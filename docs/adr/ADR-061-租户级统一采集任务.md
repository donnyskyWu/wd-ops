# ADR-061：租户级统一采集任务（假设 A1）

| 字段 | 值 |
|------|---|
| 状态 | **Accepted** |
| 日期 | **2026-08-01** |
| 关联 | ADR-047 · ADR-049 · ADR-052 · ADR-060 · PRD-M10 · API-M10 |
| 触发 | 产品授权 **假设 A1**：租户级 Channel-A 统一采集任务 + `collect_enabled` 开关；本 Slice 实现 |

## 1. 背景

既有 Spec（PRD-M10 / API-M10）默认 Channel-A **一账号一任务**（`oa_collect_task.account_id` 强关联）。运营希望：

1. 每租户 **一条** Channel-A 统一采集任务（缺失则自动创建）
2. 调度默认 **23:00**，cron 来自 `sys_param`（key `collect.schedule.cron`，默认 `0 0 23 * * ?`）
3. 账号字段 **`collect_enabled`（是否采集）**：开 → 加入统一任务成员；关 → 离开成员
4. 多账号经成员表挂到同一任务

ADR-060 将 `collect/**` 标为 Phase 2 OOS stub。产品于 2026-08-01 会话授权 **假设 A1**，对本 Slice 所需域做 carve-out（见 §6）。

## 2. 决策（假设 A1 · locked）

| # | 决策 |
|---|------|
| Q1 | Channel-A 默认路径 = **租户级统一任务**，非每账号一任务 |
| Q2 | 统一任务 `account_id = NULL`；成员在 `oa_collect_task_account` |
| Q3 | 用 `is_unified=1` + UK `(tenant_id, is_unified)` 保证每租户至多一条统一任务（非统一行 `is_unified=NULL`，MySQL 允许多 NULL） |
| Q4 | 账号开关 = `oa_account.collect_enabled`（TINYINT 0/1，默认 0） |
| Q5 | cron SSOT = `sys_param.param_key=collect.schedule.cron`；缺省写入默认值；统一任务行 `cron` 与之同步 |
| Q6 | DB 主落地 **shenyu-ops Flyway**；shenyu-system 仅菜单/权限数据（本 Slice 菜单已存在，不强制改） |
| Q7 | 代码：`football-module-ops` + `football-front` views/ops |
| Q8 | **不**在本 Slice 发明 EXTERNAL / 企微通道；Channel-D 仍按 ADR-052 |

### 2.1 与旧 Spec 的关系

| 旧条款 | 本 ADR |
|--------|--------|
| API-M10 §1.2 Channel-A `accountId` `@NotNull` | **统一任务路径豁免**：`is_unified=1` 时 `accountId` 必须为 null；成员经成员表 |
| PRD-M10「一账号一任务」运营默认 | Channel-A **默认路径**改为统一任务；历史 `is_unified IS NULL` 的单账号任务可并存（兼容），UI 引导统一任务 |
| ADR-060 `collect/**` OOS stub | 本 Slice **卸载** `/admin-api/ops/collect/task/**` stub；log/quality/EXTERNAL config 等仍可 stub |

### 2.2 Schema 选择（最小破坏）

`account_id` 已在 V136 改为可空（Channel-D）。统一任务复用可空语义，并增加：

```text
oa_collect_task.is_unified TINYINT NULL  -- 1=租户统一任务；NULL=其他
UK (tenant_id, is_unified)

oa_collect_task_account (
  tenant_id, task_id, account_id, ...
  UK (tenant_id, task_id, account_id)
)

oa_account.collect_enabled TINYINT NOT NULL DEFAULT 0
oa_account_ext.collect_enabled TINYINT NOT NULL DEFAULT 0  -- 公众号 mp SSOT 路径
```

统一任务模板字段（ensure 时写入）：

| 字段 | 值 |
|------|-----|
| `task_name` | `租户统一采集任务` |
| `platform_type` | `MULTI`（跨平台成员；执行时按成员账号平台路由） |
| `account_id` | `NULL` |
| `method` | `INTERNAL` |
| `source` | `UNIFY_COLLECTOR`（Channel-A 统一；若字典无此值则存字面量，执行期再归一） |
| `frequency` | `DAILY` |
| `cron` | 来自 `sys_param` / 默认 `0 0 23 * * ?` |
| `status` | 新建 `PENDING`；已存在不覆盖运营改过的 status |
| `is_unified` | `1` |
| `data_type` | `NULL`（全量 · ADR-049） |

## 3. 行为

1. **`ensureUnifiedTask(tenantId)`**：无则建；有则回填/同步 cron（从 param）；返回任务 id。
2. **`syncMembership(accountId, collectEnabled)`**：true → ensure + upsert 成员行；false → 软删/物理删成员行。
3. **账号 create/update** 若携带 `collectEnabled`，落库后调用 sync。
4. **调度 / run**：persist cron + 成员；follow-up 已落地多账号 runner + cron 扫描（§5）；SyncService 真落库仍后续。

## 4. API（本 Slice）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin-api/ops/collect/task/page` · `/list` | 列表（含统一任务；`memberCount` / `isUnified`） |
| GET | `/admin-api/ops/collect/task/{id}` | 详情 + 成员 accountId 列表 |

| GET | `/admin-api/ops/collect/task/{id}/members` | 成员列表（`accountId` + **`accountName`** 展示名：`oa_account.account_name` / 公众号 `mp_account.name`；`platformType` · `collectEnabled`） |
| POST/PUT | 账号 create/update | 支持 `collectEnabled` |
| POST | `.../task/{id}/start` · `stop` | 启停（改 status / next_run_at） |
| POST | `.../task/{id}/run` | 多账号执行器已落地；写 `oa_collect_log`（SUCCESS/PARTIAL/FAILED） |

权限：`ops:collect:task:list`（及既有 collect 菜单权限）。
