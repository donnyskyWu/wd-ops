# ADR-065：IP 组「关联作者」有且仅一选

| 字段 | 值 |
|------|---|
| 编号 | ADR-065 |
| 标题 | 小组关联作者有且仅一选（单选必选） |
| 状态 | **Accepted**（2026-08-02，用户口头确认） |
| 日期 | 2026-08-02 |
| 关联 | [ADR-051](./ADR-051-Ops与Football多库复用-作者域.md) · [ADR-055](./ADR-055-IP组作者单向关联.md) · PRD-M1 FR-M1-001 |

---

## 1. 背景

PRD/API 原允许 `POST .../anchors` 传入多个 `anchorUserIds`；创建弹窗另有「作者」字段仅用于填充等级，**未**写入 `oa_ip_group_anchor_rel`，导致「选了作者后关联作者 Tab 无数据」。

用户确认：**关联作者有且仅可选一个**。

---

## 2. 决策

| # | 决策 |
|---|------|
| D1 | 仅**小组**（`group_type=2`）可绑定关联作者（对齐 BR-M1-001） |
| D2 | 每个小组 **至多 1** 条 `oa_ip_group_anchor_rel`；绑定请求体 **恰好 1** 个作者 ID |
| D3 | 创建/编辑小组时表单「关联作者」为单选；创建小组时**必选**；提交后写入 SSOT（ADR-055） |
| D4 | 大组创建/编辑不展示、不提交关联作者 |
| D5 | Tab「添加作者」：已有 1 人时须先解绑再绑；后端拒绝超额绑定 |

---

## 3. 错误码

| 码 | 含义 |
|----|------|
| 1009 | 关联作者仅可绑定到小组 |
| 1010 | 关联作者有且仅可选一个 |

---

## 4. 与既有 Spec 关系

- 修订 AC-M1-001-6 隐含的「可多次添加多名作者」为 **单人**；绑定 API 仍用现有 `POST .../anchors`，请求体长度约束为 1。
- 创建弹窗字段超出 UX-M1 D-M1-001 原文，以本 ADR 为准（用户确认）。
