# ADR-073：工作任务赛事池（运营主管配置）

| 字段 | 值 |
|------|---|
| 编号 | ADR-073 |
| 标题 | 租户级工作任务赛事池 · 运营主管配置 · IP 组长严格登记 |
| 状态 | **Accepted**（产品确认 2026-08-21） |
| 日期 | 2026-08-21 |
| 关联 | FR-M2-010 · ADR-064（ops_manager）· ADR-071 |

---

## 1. 背景

IP 组长登记任务时自行选赛，与运营主管当周重点赛事不一致；任务管理矩阵统计也无法对齐「应登记场次」。

## 2. 决策（产品确认）

| # | 决策 |
|---|------|
| D1 | **租户级**赛事池：同一 `period_start`~`period_end` 内全租户 IP 组共用，最多 **10 场** |
| D2 | **运营主管**（`ops_manager` + `ops:work-task:match-config`）在「工作任务管理 → 赛事配置」Tab 维护；默认周期为**本周（周一至周日）**，可改日期范围 |
| D3 | **IP 组长登记严格模式**：只能从当期赛事池中选择；后端 `save/confirm` 校验 `competition_id ∈ pool`（按 `match_date = work_date`） |
| D4 | 新建 sheet 时，按 `work_date` **预填**当日池内赛事到登记行 |
| D5 | **任务管理矩阵**：行以配置赛事为 SSOT（无登记也显示空单元格）；`totalMatchRows` = 配置场次数；任务统计仅计配置赛事上的已确认登记 |

## 3. 数据模型

- `oa_work_task_match_pool`：`(tenant_id, period_start, period_end)` 唯一
- `oa_work_task_match_pool_item`：`pool_id` + `row_no` 1~10；存 `competition_id` 快照与 `match_date`

## 4. API

| 方法 | 路径 | 权限 |
|------|------|------|
| GET | `/ops/work-task/match-pool` | list / manage / register / match-config |
| PUT | `/ops/work-task/match-pool/save` | match-config |
| GET | `/ops/work-task/match-pool/for-register` | register |

## 5. 后果

- 无赛事池时 IP 组长无法选赛并保存（提示联系运营主管）
- 矩阵在无登记时仍可展示配置赛事行（作者列为空直至有确认登记）
