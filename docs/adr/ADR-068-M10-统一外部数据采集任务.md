# ADR-068：统一外部数据采集任务（Channel-D · 假设 B1）

| 字段 | 值 |
|------|---|
| 状态 | **Accepted** |
| 日期 | **2026-08-03** |
| 关联 | ADR-052 · ADR-061 · ADR-060 §5.3 · API-M10 · API-M8 |
| 触发 | 产品授权：租户级 Channel-D 统一外部采集任务 + 外部配置 `collect_enabled` |

## 1. 背景

ADR-061 已落地 Channel-A **租户统一采集任务**（`is_unified=1` · 默认 23:00）。运营对外部竞品账号与关键词监测提出对称能力：

1. 每租户 **一条** Channel-D 统一外部采集任务
2. 调度默认 **22:00**，cron 来自 `sys_param`（`collect.external.unified.cron`）
3. M8 外部账号（`oa_collect_config` · `scope=EXTERNAL`）与关键词（`oa_config_keyword`）增加 **`collect_enabled`**
4. 开启 → 加入统一外部任务成员；关闭 → 移出

## 2. 决策（假设 B1 · locked）

| # | 决策 |
|---|------|
| Q1 | Channel-D 默认路径 = **租户级统一外部任务**，非每配置一任务 |
| Q2 | 统一外部任务 `is_unified=2`（UK `(tenant_id, is_unified)` 与内部 `1` 并存） |
| Q3 | 成员表：`oa_collect_task_config`（外部账号配置）· `oa_collect_task_keyword`（关键词） |
| Q4 | 开关：`oa_collect_config.collect_enabled` · `oa_config_keyword.collect_enabled`（TINYINT 0/1，默认 0） |
| Q5 | cron SSOT = `sys_param.param_key=collect.external.unified.cron`；缺省 `0 0 22 * * ?` |
| Q6 | 任务模板：`task_name=统一外部数据采集任务` · `method=EXTERNAL` · `source=UNIFY_COLLECTOR_EXTERNAL` · `platform_type=MULTI` |
| Q7 | 执行：`ExternalCollectRunService` 遍历成员 → `ExternalCollectorApiClient` → 落库 `oa_external_*` |
| Q8 | **不**复用 `oa_collector_account_bind`（ADR-052） |

### 2.1 平台实现范围（本 Slice）

| 平台 | 账号采集 | 关键词采集 | 说明 |
|------|----------|------------|------|
| **KUAISHOU** | ✅ `GET /api/v1/external/kuaishou/user-videos` | ⏳ collector 无 keyword search | P0 |
| **WECHAT_OFFICIAL** | ✅ search-account + article-collect | ✅ search-account | 须租户凭账号 |
| **DOUYIN** | 🟡 仅 `parse-video`（`account_identifier` 为 video URL） | ⏳ 无 search | user-videos 待 collector P2 |
| **WECHAT_VIDEO** | ❌ stub | ❌ stub | collector P3 阻塞 |

### 2.2 凭账号

沿用 ADR-052 §3.4：`oa_tenant_collector_credential`（租户级）→ `TenantCollectorCredentialResolver`；快手 P0 可回退 env `KUAI_SHOU_COOKIE`。**公众号 P0 运维回退**（2026-08-04 addendum）：`sys_param.collect.external.wechat_official.cookie` → env `WECHAT_OFFICIAL_COOKIE`；解析顺序 **租户表 > sys_param > env**。
