# ADR-082：平台账号手机号与实名人允许一对多关联

| 字段 | 值 |
|------|---|
| 状态 | **Accepted** |
| 日期 | **2026-09-05** |
| 关联 | FR-M4-005 · ADR-062 · API-M4 §5.2 · GLOBAL-CONVENTIONS §3.2 |
| 触发 | 产品明确授权：平台账号可复用手机号与实名人关联 |

## 1. 背景

ADR-062 已允许同一实名人同时关联多个平台账号，但既有服务仍把
`oa_account.phone_id` 作为账号间独占资源。创建或编辑账号选择已被其他账号关联的手机时，
服务返回 1502「关联资源已被占用」，阻断跨平台账号共用手机号。

数据库中的 `oa_account.phone_id`、`oa_account.realname_id` 只有普通索引或无唯一索引，
不存在需要调整的唯一约束；当前阻断来自服务层占用检查。

## 2. 决策（产品授权 · locked）

1. 手机 : 平台账号 = **1:N**；同一个 `phone_id` 可同时关联多个平台账号。
2. 实名人 : 平台账号继续保持 ADR-062 的 **1:N**。
3. 新建、编辑平台账号时，`phoneId`、`realnameId` 不参与跨账号独占占用检查，
   不因已被其他账号关联而返回 1502，也不需要 `forceReplace`。
4. `phoneId`、`realnameId` 的存在性、`tenant_id` 隔离、启用状态及其他既有合法性校验保持不变。
5. 手机资产自身的手机号唯一约束不变；平台内 `external_account_id` 唯一约束不变。
6. 手机卡 `simCardId` 仍为账号间独占资源，继续执行 1502 与 `forceReplace + reason`。

## 3. 影响

- 后端：`PlatformAccountServiceImpl` 的创建、更新共用冲突解析跳过 `phoneId` 与 `realnameId`。
- 数据库：无 Flyway 迁移；不删除任何索引。
- 前端：平台账号表单取消 `<PhoneSelect />` 的“已绑定手机不可选”过滤；手机卡过滤保持。
- 计数：`account_bound_count` 继续按账号关联增减，允许大于 1。

## 4. 验收

- 新建账号可复用已关联的手机号、实名人。
- 编辑账号可改为其他账号已关联的手机号、实名人。
- 不存在、停用、跨租户的手机号或实名人仍拒绝。
- 已占用手机卡仍拒绝；同平台账号标识重复仍拒绝。
