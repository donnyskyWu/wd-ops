# ADR-078 · M4 抖音/快手双状态、登录密码与 Excel 0928 导入

| 状态 | **Accepted**（用户 2026-09-28 明确覆盖 Spec 缺口） |
|------|------------------------------------------------------|
| 关联 | PRD-M4 · API-M4 · UX-M4 · `scripts/import/generate_accounts_from_xlsx.py` |

## 背景

Excel `抖音号_快手号分配(0928).xlsx` 要求入库：**密码**、**短视频状态**、**直播状态**；映射 **持有人→holderUserId**、**运营人→operatorUserId**、**分配小组→ipGroupId**（可选）。Spec 未单独定义抖音/快手双状态字段。

## 用户 SSOT 映射（Excel / 表单 / 导入 · 客户 2026-09-28 覆盖）

| 来源 | 目标 | 说明 |
|------|------|------|
| Excel **「持有人」**（快手 L「持有人」/ R「持有」） | 系统 **持有人** `holder_user_id` / API **`holderUserId`** | **V205**；`user_map.json` 姓名 → Football `system_users.id`；导入 SQL **写入** |
| Excel **「运营人」** | 系统 **运营人** `operator_user_id` / API **`operatorUserId`** | **V206**；同上 `user_map.json` |
| 表单 **「持有人」** | `holder_user_id` / **`holderUserId`** | 与 Excel「持有人」**同一字段**，非 Football/Excel 双轨 |
| 合规 **实名人** | `realname_id` / **`realnameId`** | 导入用 Excel 持有人姓名 **并行** 建/链 `oa_realname`；DOUYIN 仍配合 `company_id` 后端校验 |

**禁止**仅把 Excel「持有人」写入 `realname_id` 而不解析 `holderUserId`（当列内有姓名且可映射 Football 用户时）。

### §用户 SSOT replacement（相对旧版 ADR-078 草案）

- 旧：Excel 持有人 = 实名人 only；holderUserId 仅表单手工。
- 新：Excel/表单「持有人」= `holderUserId` SSOT；`realname_id` 为合规从属（同名档案，不占「持有人」语义）。
- 实名人路径：最小实现 — `generate_accounts_from_xlsx.py` 继续从持有人列去重建 `oa_realname`，不替代 `holder_user_id`。

## 决策

| # | 决策 |
|---|------|
| D1 | **双状态** 使用 `oa_account.short_video_status`、`oa_account.live_status`（VARCHAR 128，存 Excel 原文，非字典枚举） |
| D2 | **直播/短视频** 不用 `oa_account_status_log` 替代主数据（日志仍可用于采集快照） |
| D3 | **密码** 复用 `oa_account.password_encrypted`（AES-256，与公众号同列）；列表/详情 **脱敏**，表单可改 |
| D4 | **持有人** `holder_user_id`、**运营人** `operator_user_id`（均为 Football `system_users.id`）；API **`holderUserId`** / **`operatorUserId`**。Excel 列分别经 `user_map.json` 入库；**并行** `realname_id` 合规链 |
| D5 | **ip_group_id** 已有列；导入经 `--ip-group-map` + 组名模糊匹配 |
| D6 | **跳过** 卖家微信、截图；**不导入** 粉丝、购买价格、运营人费用（本期） |
| D7 | Flyway **V206**；后端 `AccountCreateReq`/`AccountUpdateReq`/`AccountRespVO` 在 `DOUYIN`/`KUAISHOU` 暴露上述字段；前端 InternalAccountManage 抖音/快手 Tab 增表单项 |
| D8 | 导入 SQL **默认仅生成**；test 库执行需人工确认 + `apply-import-accounts.py` |

## 快手 Sheet

- 表头行：**第 2 行**（`header=1`）
- 数据行：22 行（不含表头）
- **双列账号**：同一 Excel 行可拆 **左**（`快手ID`）+ **右**（`ID`）；右块独立账号当 `ID` 非空
- 左块双状态：`仅发短视频`→`short_video_status`（「是」→「仅发短视频」）、`短+直播`→`live_status`（「是」→「短+直播」）

## 抖音 Sheet

- Sheet 名 **`20W抖音`**（别名 `抖音`）
- 表头行 1；数据约 91 条有效 `抖音ID`
- `短视频状态` / `直播状态` / `抖音密码` 直接映射

- 购买价格 / 运营人费用 → `oa_account_cost`
