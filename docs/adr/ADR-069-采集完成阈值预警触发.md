# ADR-069：采集完成阈值预警触发

| 字段 | 值 |
|------|---|
| 状态 | **Accepted** |
| 日期 | **2026-08-04** |
| 关联 | ADR-026 · ADR-056 · ADR-061 · ADR-068 · PRD-M8 · API-M8 |
| 触发 | 用户锁定 Q1/Q3/Q5/Q6 决策 · P0 后端切片 |

## 1. 背景

M8 阈值规则（`oa_threshold_config`）已可配置 FANS / WORK 类阈值；M9 通知基础设施（`NotificationServiceImpl` · `sys_notification_event` 去重）已落地。采集任务（ADR-061 内部统一 · ADR-068 外部统一）每次 run 后会写入 `oa_collect_log`，但**未**在采集完成后增量评估阈值并推送预警。

PRD-M7 原 Scope 仅覆盖外部竞品；用户决策 **Q5** 将内部统一采集纳入同等预警范围。

## 2. 用户决策（locked）

| # | 决策 |
|---|------|
| **Q1** | **双触发**：① 采集 run 完成（SUCCESS / PARTIAL）后异步增量评估；② cron 兜底全租户扫描（P1 stub） |
| **Q3** | **低粉双定义**：(a) M8 FANS `lowFans` 绝对值；(b) M7 连续 7 日粉丝下降（`oa_follower_daily.net_growth` 序列；`dailyLow` 有值时以 `net_growth <= dailyLow` 计为下降日） |
| **Q5** | **是** — 内部统一采集（Channel-A）须触发爆款 / 低分作品预警（扩展 PRD-M7 OOS 外部-only 边界） |
| **Q6** | 外部账号/作品**无 IP 组**时，通知 **`oa_collect_config.creator`**（TenantBaseDO.creator → Football `system_users.id` 字符串，ADR-056） |

## 3. 架构

### 3.1 Hook 点

```
UnifiedCollectRunService.run()
  → collectLogMapper.insert(logRow)
  → applyPostRunTaskState + update task
  → CollectThresholdTriggerService.triggerAfterCollect(@Async)   // SUCCESS | PARTIAL only
```

### 3.2 新增组件

| 类 | 职责 |
|----|------|
| `CollectThresholdTriggerService` | 解析 run 上下文成员 → 增量查库 → 调用 judge + notify |
| `ThresholdJudgeService` | FANS（高/低绝对 + 7 日连降）· WORK（hotValue / lowValue 自配置）纯判定 |
| `ThresholdMetricResolver` | 读 `oa_threshold_config` ENABLED 规则；默认值与 Monitor 列表对齐 |
| `ThresholdAlertRecipientResolver` | 内部 → IP 组组长；外部无 IP 组 → collect_config.creator |
| `MonitorAlertScanner` | **P1 stub**：`@Scheduled` 读 `monitor.scan.cron`，委托同一 judge 全租户扫描 |

### 3.3 通知

沿用 ADR-026 四事件：

| event_type | 判定 |
|------------|------|
| `WORK_HIT` | 播放/阅读 ≥ `hotValue`（默认 100 万）；或内部 `is_hit=1` |
| `WORK_LOW_SCORE` | 完播率 < `lowValue`%（默认 20）；仅外部作品有 `completion_rate` 时 |
| `ACCOUNT_HIGH_FANS` | 粉丝 ≥ `highFans`（默认 100 万） |
| `ACCOUNT_LOW_FANS` | 粉丝 ≤ `lowFans` **或** 连续 7 日下降（Q3 双轨 OR） |

`biz_key` 示例：`account:{id}:ACCOUNT_LOW_FANS:{statDate}` · `external-work:{id}:WORK_HIT` · `internal-work:{id}:HIT`

### 3.4 增量 Scope（P0）

| 任务类型 | 成员 | 评估实体 |
|----------|------|----------|
| `is_unified=1` | `oa_collect_task_account` | `oa_account` + `oa_follower_daily` + `oa_content` + 平台表 |
| `is_unified=2` | `oa_collect_task_config` / keyword | `oa_external_account` + `oa_external_work` |
| 单账号 | `task.accountId` | 同内部 |

仅处理本次 run 涉及的 member id；cron 扫描（P1）补漏。
